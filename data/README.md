# Dados

Esta pasta concentra a documentação dos dados utilizados na prova de conceito.

## Regras

- não versionar dados pessoais ou identificadores reais;
- documentar a origem de cada campo;
- identificar se cada variável é observada, derivada, sintética, parametrizada por fonte técnica ou parametrizada com base na comunidade externa.
