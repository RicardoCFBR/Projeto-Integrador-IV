# Guia de Contribuição

## Fluxo de trabalho

1. Atualize a branch `main`.
2. Crie uma branch específica para a tarefa.
3. Faça alterações pequenas e rastreáveis.
4. Escreva commits objetivos.
5. Abra um Pull Request descrevendo o que foi feito, como testar, limitações e evidências.

## Padrão de branches

- `feat/nome-da-funcionalidade`
- `fix/nome-do-problema`
- `docs/nome-do-documento`
- `chore/nome-da-tarefa`
- `test/nome-do-teste`

## Regras

- não subir senhas, tokens, chaves ou arquivos `.env`;
- não subir dados reais identificáveis;
- toda evidência técnica apresentada no relatório deve ser reproduzível;
- diferenciar claramente dados reais, parâmetros reais e dados sintéticos;
- não apresentar funcionalidade planejada como implementada.
